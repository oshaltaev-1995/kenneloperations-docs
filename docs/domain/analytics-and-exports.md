# Analytics and exports

Analytics presents:

- Overview;
- Weekly Comparison;
- Current Housing Summary;
- Dog Weekly Summary.

Work totals come from the authoritative meaningful-activity projection. Removed sessions and zero-work chronology records are not treated as completed work, and Worklog compatibility rows are not double-counted with their canonical activity records.

## Current Housing Summary

The report selects work for the requested period, then groups it under housing current at the report's reference time. It answers “where do the dogs represented by this work live now?” It is **not** historical kennel-location utilization and must not be interpreted as where each run occurred.

## Outputs

Analytics supports XLSX, PDF, and CSV outputs according to the report endpoint. TULOSTE is not an Analytics export; it belongs to Daily Entry and follows the selected Daily Entry date's housing layout.

Archive summary metrics and seasonal calculations continue to use the full stored authoritative history even though Archived/Deceased Dog Detail displays only the latest ten meaningful work rows when expanded.
